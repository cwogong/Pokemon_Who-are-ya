# 포켓몬스터 Who are ya? 🕵️‍♂️🔍

랜덤으로 선정된 미지의 포켓몬을 추리하여 맞추는 웹 기반 웹 게임입니다. 축구 선수 맞추기 'Who are ya?'의 포켓몬 버전으로, 제한 없이 주어지는 힌트를 통해 정답을 좁혀나가는 재미를 느낄 수 있습니다.

---

## 🎮 게임 규칙
플레이어가 포켓몬 이름을 입력하면, 정답 포켓몬과의 일치 여부에 따라 다음과 같은 단서를 제공합니다.

*   **비교 속성:** 타입, 세대, 진화단계(1~3, 진화없음), 키, 몸무게를 비교합니다[cite: 1].
*   **색상 힌트:** 
    *   🟩 **초록색:** 해당 속성이 정답과 완벽하게 일치함
    *   ⬜ **회색:** 해당 속성이 정답과 일치하지 않음
*   **업다운 힌트:** 키와 몸무게는 정답보다 큰지(↓), 작은지(↑) 파란색과 빨간색 화살표로 알려줍니다.
*   **포획 등급:** 정답을 맞힌 시도 횟수에 따라 마스터볼(7회 이하), 하이퍼볼(10회 이하), 슈퍼볼(14회 이하), 몬스터볼(15회 이상) 랭크가 부여됩니다.

---

## ✨ 주요 기능
*   **자동완성 검색:** 포켓몬의 이름을 일부만 입력해도 드롭다운 목록에서 쉽게 찾고 선택할 수 있습니다.
*   **무제한 재도전:** '🔄 다시 하기' 버튼을 통해 새로고침 없이 즉시 새로운 포켓몬으로 게임을 다시 시작할 수 있습니다.
*   **포기하기:** 도저히 모르겠다면 '🏳️ 포기하기' 버튼으로 정답 포켓몬의 사진과 이름을 바로 확인할 수 있습니다.
*   **직관적인 UI:** 플레이어가 유추하기 쉽도록 입력한 포켓몬의 공식 일러스트가 함께 출력됩니다.
